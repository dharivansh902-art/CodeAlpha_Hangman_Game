
# Hangman Game - CodeAlpha Internship

## Project Overview
Hangman is a word guessing game developed using Python.

The player has to guess a hidden word by entering one letter at a time.

## Features
- Random word selection
- Letter guessing system
- 6 maximum wrong attempts
- Input validation
- Win and lose conditions

## Technologies Used
- Python
- Random Module

## How to Run
1. Install Python.
2. Download the project.
3. Open the folder in VS Code.
4. Run this command:

python hangman.py
